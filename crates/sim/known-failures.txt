# Each line is SEED CONFIG MODE, then every property kind the run breaks and
# the State::validate message it stops on, if any. A run is known only if it
# fails exactly as listed; the test suite and `celld-sim --known` fail on any
# other failure and on a listed seed that no longer fails as listed. Every
# failure here is one of the core bugs in docs/testing.md, which
# `the_known_failures_are_known_core_bugs` in crates/sim/tests/sim.rs checks
# by kind and by message.
#
# - chaos, true-clocks, crashes and crashes-fleet are the test suite's own
#   configurations. Its failing tests print the lines they need.
# - swarm covers seeds 0..10000 of SimConfig::swarm, in both modes:
#   `celld-sim --swarm --seeds 0..10000 --record` prints the lines, in a
#   build with debug assertions on (validated) and off (unvalidated).
#
# When a change alters a run, trace the seed before changing its line. When a
# core fix lands, its seeds stop failing and their lines go.
